## Lessons Learned About Clean Code
So far in this subject, I have learned several key lessons about writing clean, maintainable, and professional code: 
- Meaningful naming: Choose clear, descriptive names for variables, functions,a dn classes to make code easy to follow so that others are able to pick up where you left off. 
- DRY Principle (Don't Repeat Yourself): Avoid code duplication by reusing functions (refactoring using extract method has come in handy)
- Consistent styling: Follow coding conventions such as those in the styles guide and programming patterns ingrain good coding practices as these are designed to be used in industry.
